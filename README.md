# 🎨 Malooky — منصة الكاليجرافيتي العربي

منصة تعليمية متكاملة لتعلم فن الكاليجرافيتي (خط الجدران العربي العصري) — Next.js 15 + Supabase + Stripe + Bunny Stream.

## ✨ المميزات

| المجال | التفاصيل |
|---|---|
| 🎓 **كورسات بمستويات** | كورس رئيسي بمستويات متسلسلة (تأسيسي → متقدم) — الأدمن يضيف مستويات بأي أسماء |
| 🔗 **علاقات الكورسات** | `متسلسل` (يُفتح بعد 100% من السابق) أو `مستقل` (يُفتح مباشرة) |
| 📂 **أقسام فرعية** | تمارين (+ روابط Drive) · طريقة الكتابة · الأخطاء الشائعة · الفيد باك (نجوم) · الأسئلة الشائعة |
| ✅ **تتبع الإكمال** | إكمال كل فيديو — المستوى التالي يُفتح عند 100% فقط |
| 🌐 **دبلجة لغات** | كل لغة فيديو مستقل مرفوع منفصلاً — تبديل اللغة من المشغّل لكل الفيديوهات |
| 💳 **الدفع** | Stripe (بطاقة/كوبونات) + تحويل يدوي بإثبات عبر واتساب — كلها من DASH |
| 📦 **الباقات** | كورس مفرد، حزمة شاملة، أو كورسات مختارة — من DASH |
| 🎁 **التبرعات** | مبالغ جاهزة أو مخصص عبر Stripe Checkout |
| 🔒 **أمان الفيديو** | روابط موقّعة قصيرة الأجل + HLS AES-128 + علامة مائية باسم المشاهد |
| 🏆 **محتوى تشويقي** | أفضل التعليقات · أفضل الطلاب · أعمال الطلاب (بموافقة الإدارة) |
| 🎥 **VIP مباشرة** | مفتاح تشغيل/إبطال بضغطة من DASH |
| 🧠 **ذكاء الكورس الواحد** | كورس واحد = عرض مباشر بلا تحليلات — أكثر من كورس = شبكة + شارات «جديد» |
| 👥 **الطلاب** | يضيفهم الأدمن يدوياً أو بعد الشراء — مع استثناءات فتح أي مستوى |

## 🚀 التشغيل المحلي

أنشئ ملف `.env` محلياً من القالب، ثم أضف إعدادات الخدمات الخاصة بك إلى الملف المحلي:

```powershell
Copy-Item .env.example .env
npm run dev
```

يحمّل Next.js متغيرات البيئة من `.env` و`.env.local` تلقائياً عند تشغيل `npm run dev`. لا يلزم أي إعداد إضافي لتشغيل خادم التطوير. يبقى `.env` و`.env.local` في `.gitignore`؛ لا تشارك محتوى الملف أو ترفعه إلى Git.

إذا لم تكن متغيرات Supabase صالحة، فلن تتصل صفحات الموقع بقاعدة البيانات وستعرض حالة الإعداد/المحتوى الفارغ بدلاً من بيانات مستخدمين وهمية. أضف أسرارك محلياً فقط، ثم أعد تشغيل خادم التطوير بعد تعديلها.

## 🔑 متغيرات البيئة

أسماء المتغيرات المطلوبة موثقة مع قيم قالب غير سرية في `.env.example`:

- Supabase: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` (مفتاح الخدمة للسيرفر فقط).
- Bunny Stream: `BUNNY_LIBRARY_ID`, `BUNNY_STREAM_KEY`, `BUNNY_TOKEN_AUTH_KEY`.
- Stripe: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`.
- الموقع: `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_CURRENCY`.

ضع القيم الحقيقية في `.env` المحلي فقط؛ لا تضعها في المصدر أو `.env.example` ولا ترسلها في المحادثات.

## 🗄️ قاعدة البيانات

شغّل `supabase/schema.sql` كاملاً في **SQL Editor** بلوحة Supabase — ينشئ:
- كل الجداول + RLS كامل (الطالب يرى تقدمه فقط، المحتوى المنشور للعموم، الأدمن يدير كل شيء)
- الإعدادات الافتراضية لطرق الدفع؛ أضف الكورسات والمستويات والدروس الفعلية من لوحة الإدارة.

ثم أنشئ Storage bucket باسم `manual-proofs` (**private**) لإيصالات التحويل اليدوي.

لترقية قاعدة بيانات موجودة دون إعادة تشغيل المخطط الكامل، شغّل `supabase/migrations/20261001000000_admin_audit.sql` في SQL Editor. ينشئ هذا سجل تغييرات الأدمن المحمي بـRLS. يجب تشغيله قبل استخدام تبويب «سجل التغييرات»؛ إذا تعذّر التسجيل بعد نجاح إجراء إداري، ستظهر رسالة تحذير في اللوحة.

الكورسات الجديدة تُنشأ كمسودات. يتطلب النشر تأكيداً صريحاً، وعنواناً وسعراً صالحين (إلا إذا كان الكورس مجانياً) ومستوى ودرساً واحداً على الأقل. إلغاء النشر قابل للعكس ويحتفظ بالدروس والوصولات؛ الحذف النهائي للكورس معطّل من لوحة الإدارة لتجنّب فقد البيانات.

### أول حساب أدمن
1. سجّل دخول عادي من `/login` بعد إنشاء مستخدم من Supabase → Authentication → Add User.
2. في SQL Editor: `update profiles set role='admin' where email='you@example.com';`

## 🎥 إعداد Bunny Stream (أمان الفيديو)

1. أنشئ **Stream Library** وفعّل **HLS AES-128 (File DRM)** من إعداداتها — هذا يشفّر الفيديوهات نفسها.
2. من إعدادات الـ Pull Zone فعّل **Token Authentication** وانسخ المفتاح إلى `BUNNY_TOKEN_AUTH_KEY`.
3. (اختياري لاحقاً) فعّل **DRM (Widevine/FairPlay)** لمعاقبة الأدوات الاحترافية.
4. ارفع الفيديو لكل لغة على حدة من Bunny → انسخ **Video ID** → اربطه بالدرس من DASH (🔗 ربط فيديو).

> ⚠️ **حقيقة تقنية**: منع تصوير الشاشة بكاميرا خارجية مستحيل تقنياً على الويب — لكن العلامة المائية
> المتحركة باسم/بريد المشاهد تجعل أي تسريب قابل للتتبع والمعاقبة قانونياً، وهي أفضل ممارسة عملية
> (نفس أسلوب Domestika وUdemy وMasterClass).

## 💳 إعداد Stripe

1. أضف `STRIPE_SECRET_KEY` في البيئة.
2. Webhook endpoint: `https://malooky.com/api/stripe/webhook` — حدث واحد: `checkout.session.completed`.
3. انسخ `whsec_...` إلى `STRIPE_WEBHOOK_SECRET`.
